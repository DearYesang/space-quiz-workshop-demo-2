# 우주 탐사 퀴즈 실습

서버나 외부 의존성 없이 실행하는 단일 HTML 우주 탐사 퀴즈입니다.

## 실행

`index.html`을 브라우저로 엽니다. Windows PowerShell에서는 프로젝트 폴더에서 다음 명령으로 실행할 수 있습니다.

```powershell
Start-Process .\index.html
```

## 구성

- `index.html`: 10문항, 진행률, 점수, 정답·오답 애니메이션, 이모지 결과 화면과 점수 카운트업을 포함한 퀴즈
- `README.md`: 실행 방법과 실습 지침
- `.gitignore`: 비밀 정보와 로컬 작업 파일 제외 규칙

## 실습 지침

- HTML, CSS, JavaScript는 `index.html` 안에 유지하고 서버나 외부 라이브러리를 추가하지 않습니다.
- 변경 시 한국어 화면과 키보드 조작을 유지합니다. Tab으로 버튼을 이동하고 Enter 또는 Space로 선택합니다.
- 브라우저에서 정답·오답, 10문항 완료, 결과 점수와 다시 도전하기를 확인합니다.
- 운영체제의 라이트·다크 설정과 동작 줄이기 설정에서도 화면을 확인합니다.
- 커밋 전 변경 파일을 검토하고 토큰, 비밀번호, 개인 환경 설정은 게시하지 않습니다.
